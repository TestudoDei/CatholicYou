# CatholicYou

CatholicYou is a calm, trustworthy companion for living the Catholic liturgical year. The first release will help readers discover saints and feast days, begin novenas on time, and choose exactly which reminders they receive.

## Current version

The repository contains the initial public homepage and the project’s engineering and editorial guardrails. Its sample content demonstrates the intended experience; publication workflows and email delivery will be added behind explicit review gates.

## Local development

Requires Node.js 22.13 or newer.

```bash
npm install
npm run dev
```

Build and test with:

```bash
npm test
```

## Product principles

- Devotional, never sensational
- Carefully sourced and transparent about tradition
- Quiet, accessible design
- Explicit email preferences with one-click unsubscribe
- Human review before Catholic content is published

See `AGENTS.md` for repository rules and `docs/EDITORIAL_GUIDE.md` for the content standard.
